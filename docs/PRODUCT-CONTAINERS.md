# GRUNDKRAFT Product Container System

Status: **visual direction locked for refinement**

The current mockup product tubs are treated as master packaging references. They should not be replaced by generic supplement jars.

## Shared container geometry

All core powder products use the same recognizable family:

- squat cylindrical tub
- matte black body
- broad black ribbed screw lid
- rounded shoulder
- straight lower body
- dark label field
- narrow high-contrast product-color band near the upper label
- centered GRUNDKRAFT `G` mark
- large condensed product name
- compact secondary descriptor beneath
- minimal legal/detail copy near the bottom

The container should feel durable, workshop-grade and premium, not clinical.

## Material impression

- body: matte charcoal/black HDPE look
- lid: slightly darker black with visible ribs
- label: satin/matte, no mirror gloss
- highlights: narrow and realistic
- shadow: tight dark studio shadow

## Label architecture

Top to bottom:

1. product-color band
2. centered GRUNDKRAFT `G`
3. large product name
4. small descriptor / flavor
5. restrained technical/legal microcopy
6. optional weight/quantity bottom corner

The product name must dominate at thumbnail size.

## Product color variants

### TAGWERK

- Accent: orange `#E15313`
- Product role: daily workday hydration/energy system
- Label mood: energetic, warm, immediate
- Current flavor reference: Yuzu-Zitrone

### STANDFEST

- Accent: industrial blue `#355582`
- Product role: reserved for the stable/support-oriented product family
- Label mood: dependable, technical, calm

### KRAFTRESERVE

- Accent: workwear green `#456C4F`
- Product role: strength reserve / creatine direction
- Label mood: durable, physical, grounded

## Consistency rules

- Same tub silhouette across the family where packaging volume allows
- Same logo position
- Same label proportions
- Same typography hierarchy
- Only product accent, product name and product-specific descriptor change
- Avoid turning every SKU into a completely different design

## Store presentation

Product containers are not secondary decoration. They are a central part of the shop identity.

Use them in:

- homepage hero overlap
- product hero sections
- “Dein Werkzeugkasten” carousel
- collection cards
- bundles
- mobile product strips
- B2B package visuals

## Refinement backlog

Before final production artwork:

- refine exact tub proportions using manufacturer dimensions
- refine lid rib count and shoulder geometry
- finalize `G` logo artwork
- choose final display font
- finalize label grid
- confirm print-safe product colors
- add legally required food/supplement information
- create front, 3/4 and side packshots
- create transparent-background PNG/WebP exports
- create high-resolution print artwork separately from ecommerce renders

## Important

These are design references only. Ingredient lists, claims, weights, quantities, origin statements and nutrition data shown in visual concepts are not automatically approved product facts and must be replaced with final verified data before launch.
